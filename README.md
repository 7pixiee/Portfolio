# Pixie — Personal Portfolio ✨

A personal portfolio website designed and developed by **Sumayya Belal**, showcasing my projects, skills, and creative approach to frontend development.

🔗 **Live Website:** [Pixie Portfolio](https://7pixiee.github.io/Portfolio/)

## About the Project

Pixie is my personal developer portfolio, built to showcase my journey as a BCA student and creative developer. It combines a dark aesthetic with soft pink accents, clean layouts, and interactive UI elements to create a distinctive digital experience.

The portfolio highlights my frontend development skills, selected projects, and interest in creating thoughtful, playful, and user-friendly web experiences.

## Features

- **Personal Introduction** - A hero section introducing me and my work.
- **Creative Services** - Highlights my interests in web development, UI development, and creative coding.
- **Featured Projects** - Showcases selected projects with descriptions, technology tags, live demos, and GitHub repositories.
- **About Me** — Shares my background, interests, and development journey.
- **Skills & Tools** - Displays the technologies and tools I use.
- **Resume Access** - Provides access to my resume PDF.
- **Contact & Social Links** - Connects visitors to my email, GitHub, and LinkedIn.
- **Interactive UI** - Includes hover effects, animated project cards, and smooth visual transitions.
- **Responsive Layout** - Uses responsive styling for different screen sizes.
